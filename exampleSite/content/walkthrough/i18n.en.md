# {{% param "title" %}}

Since Hugo has it pre-configured, internationalization is of course available with this theme! How?
Easy, by defining the available languages of your website in the `hugo.(yaml|toml)` configuration file:

```yaml
locale: en
defaultContentLanguage: en

languages:
  fr:
    contentDir: content
    label: Français
    params:
      pre: /static/primer/globe-16.svg # display an icon before language name in languages choice
  en:
    contentDir: content
    label: English
    params:
      pre: /static/primer/globe-16.svg # display an icon before language name in languages choice
```

The code snippet above is an example, more information on how to configure languages with Hugo can be found [here](https://gohugo.io/methods/site/languages/).
